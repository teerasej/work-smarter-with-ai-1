# Teerasej's Work Smarter with AI

สวัสดีครับ ยินดีต้อนรับสู่ชุด exercises "Work Smarter with AI" ที่พลออกแบบและปรับจูนเนื้อหามาอย่างต่อเนื่อง เพื่อให้พวกเราได้เริ่มเรียนรู้การใช้งานแอพเอไอ ของ Microsoft ได้เป็นลำดับขั้นตอน โดยเริ่มจากพื้นฐานไปจนถึงเทคนิคต่างๆ  ในการทำงานประจำวันอย่างมีประสิทธิภาพครับ

## ก่อนเริ่ม

- ใช้บัญชีงานหรือสถานศึกษาที่เข้าถึง Microsoft 365 Copilot ได้ตามสิทธิ์ขององค์กร
- อย่าอัปโหลดไฟล์ข้อมูลจริงที่เป็นความลับ ใช้เฉพาะไฟล์ตัวอย่างจาก repository นี้
- ความสามารถบางรายการ เช่น Copilot Create, Copilot Pages และ Agent Builder จะขึ้นกับ license ของเรา, tenant policy, หรือการตั้งค่าจากผู้ดูแลระบบนะครับ; หากไม่พบหรือไม่มี ให้ใช้แบบฝึกหัดแบบ fallback ที่แต่ละกิจกรรมระบุไว้นะ

## กติกาไฟล์ตัวอย่าง

โฟลเดอร์ [`files/`](files/) เก็บเฉพาะไฟล์ที่ผู้เรียนเปิด ใช้เป็นบริบท หรือแก้ไขระหว่างทำงาน เช่น DOCX, XLSX, PPTX, PDF และ VTT เท่านั้น ภาพ UI และภาพประกอบคำสั่งอยู่ในโฟลเดอร์ `images/` ของแบบฝึกหัดแต่ละส่วน ไม่อยู่ใน `files/`.
