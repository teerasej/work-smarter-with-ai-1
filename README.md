# Teerasej's Work Smarter with AI

ชุดแบบฝึกหัดนี้เป็นภาษาไทยเป็นหลัก โดยคงชื่อผลิตภัณฑ์และ UI ของ Microsoft เป็นภาษาอังกฤษ ใช้ตามลำดับด้านล่าง และบันทึกผลไว้ในไฟล์ตัวอย่างที่ระบุ

## ก่อนเริ่ม

- ใช้บัญชีงานหรือสถานศึกษาที่เข้าถึง Microsoft 365 Copilot ได้ตามสิทธิ์ขององค์กร
- อย่าอัปโหลดข้อมูลจริงที่เป็นความลับ ใช้เฉพาะไฟล์ตัวอย่างจาก repository นี้
- ความสามารถบางรายการ เช่น Copilot Create, Copilot Pages และ Agent Builder อาจขึ้นกับ license, tenant policy, region หรือ admin setting; หากไม่พบ ให้ใช้ fallback ที่แต่ละกิจกรรมระบุไว้

## สารบัญแบบฝึกหัด

1. [Part 1 — Create better prompts](exercises/part-1-good-prompts/README.md) — ฝึกเพิ่ม Goal, Context, Source และ Expectations ทีละส่วน พร้อม [prompt-comparison worksheet](files/part-1/prompt-comparison-worksheet.docx)
2. [Part 2 — Copilot Basic](exercises/part-2-copilot-basic/README.md) — Copilot Chat, Copilot Create, Prompt Gallery, Copilot Pages และ Copilot-in-Action พร้อม [ไฟล์งาน Part 2](files/part-2/)
3. [Part 3 — Core workflow](exercises/part-3-core-workflow/README.md) — OneDrive, Chat/Create, Word, Excel, Outlook/Teams, PowerPoint และ Agent Builder พร้อม [ไฟล์งาน Part 3](files/part-3/)

## กติกาไฟล์ตัวอย่าง

โฟลเดอร์ [`files/`](files/) เก็บเฉพาะไฟล์ที่ผู้เรียนเปิด ใช้เป็นบริบท หรือแก้ไขระหว่างทำงาน เช่น DOCX, XLSX, PPTX, PDF และ VTT เท่านั้น ภาพ UI และภาพประกอบคำสั่งอยู่ในโฟลเดอร์ `images/` ของแบบฝึกหัดแต่ละส่วน ไม่อยู่ใน `files/`.
