# Exercise: สร้าง Infographic-style visual ด้วย Copilot Create

## Exercise Overview

เราจะใช้ Copilot Create สร้างสื่อภาพที่อธิบาย Copilot Chat ให้เข้าใจง่าย แล้วตรวจความถูกต้องของข้อความก่อน Download

## Prerequisites

1. มีบัญชีองค์กรที่ใช้ Microsoft 365 Copilot Create ได้
2. เปิด [Microsoft 365 Copilot Create](https://m365.cloud.microsoft/create) บน Web browser

## Scenario 1: สร้างสื่อแนะนำ Copilot Chat

## Practice 1: สร้างและตรวจ Infographic-style visual

#### Steps

1. ลงชื่อเข้าใช้ Microsoft 365 Copilot ด้วยบัญชีองค์กร
2. เลือก **Create** จากเมนูด้านซ้าย
3. เลือก **Image** หรือ **Poster** ตามตัวเลือกที่ปรากฏใน tenant
4. วาง prompt ด้านล่างในช่องอธิบายสิ่งที่ต้องการสร้าง

```text
Create a clean infographic-style visual titled "What is Copilot Chat?"
Use a professional workplace style and a clear left-to-right reading order.
Include these three short points only:
1. Ask questions using natural language
2. Draft, summarize, and analyze information
3. Review sources and verify important details
Use simple icons, high contrast, and enough empty space for easy reading.
Do not add logos, statistics, or claims that are not in this prompt.
```

5. เลือก template, size และสีที่เหมาะกับการสื่อสารภายในองค์กร
6. เลือก **Create** แล้วรอผลลัพธ์
7. ตรวจข้อความทุกจุด โดยเฉพาะการสะกดและข้อความที่ Copilot อาจเพิ่มเอง
8. หากข้อความผิด ให้แก้ prompt หรือลองสร้างใหม่ก่อน Download
9. เลือกผลลัพธ์ที่อ่านง่ายที่สุด แล้วเลือก **Download**

> ชนิดสื่อและ template ที่เห็นอาจแตกต่างกันตาม subscription และการตั้งค่าขององค์กร ให้ใช้ **Image** หรือ **Poster** ที่มีอยู่แทนการค้นหาชื่อ template จากภาพตัวอย่างเก่า

## Checkpoint

- สื่อมีหัวข้อและสารสำคัญครบ 3 ข้อ
- ไม่มี logo, ตัวเลข หรือข้อกล่าวอ้างที่ไม่ได้กำหนดใน prompt
- ข้อความอ่านได้ชัดและไม่มีการสะกดผิดก่อน Download

## Expected Output

- Infographic-style visual 1 ภาพที่ Download แล้วและพร้อมนำไปตรวจทานต่อ
