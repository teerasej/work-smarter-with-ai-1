# Exercise: จัดการข้อมูลและทำงานร่วมกันด้วย Copilot Pages

## Exercise Overview

เราจะเปลี่ยนคำตอบจาก Copilot Chat ให้เป็น Page ที่แก้ไขได้ เก็บไว้ใช้ต่อ และแชร์ให้เพื่อนร่วมทีมช่วยตรวจเนื้อหา

## Prerequisites

1. ลงชื่อเข้าใช้ [Microsoft 365 Copilot](https://microsoft365.com/) ด้วยบัญชีองค์กร
2. บัญชีมี SharePoint หรือ OneDrive storage
3. มีเพื่อนร่วมทีม 1 คนสำหรับทดสอบการแชร์ หรือใช้ผู้สอนเป็นผู้รับ

> Copilot Pages ใช้ได้กับบัญชีองค์กรที่มี SharePoint หรือ OneDrive storage แม้ไม่มี Microsoft 365 Copilot add-on license ทั้งนี้ policy ขององค์กรอาจจำกัดการแชร์

## Scenario 1: สร้าง Project Brief สำหรับทำงานร่วมกัน

ทีมกำลังเตรียมโครงการปรับปรุงกระบวนการทำงาน เราจะใช้ Copilot ช่วยสร้าง Project Brief แล้วเปิดเป็น Page เพื่อให้ทีมตรวจและเติมรายละเอียดร่วมกัน

## Practice 1: สร้างคำตอบที่พร้อมนำไปทำ Page

#### Steps

1. เปิด **Copilot Chat** และเริ่ม Chat ใหม่
2. วาง prompt ด้านล่าง แล้วกด **Send**

```text
สร้าง Project Brief ภาษาไทยสำหรับโครงการลดเวลาการจัดทำรายงานประจำสัปดาห์
จัดโครงสร้างเป็น:
- เป้าหมาย
- ขอบเขตงาน
- ผู้เกี่ยวข้อง
- ตัวชี้วัดความสำเร็จ 3 ข้อ
- แผนงาน 4 สัปดาห์ในรูปแบบตาราง
- ความเสี่ยงและแนวทางรับมือ
หากไม่มีข้อมูลเจ้าของงาน วันที่ หรือตัวเลขเป้าหมาย ให้ใส่ [ต้องระบุ] แทนการคาดเดา
```

3. ตรวจว่าคำตอบมีหัวข้อครบและไม่มีข้อมูลที่ Copilot คาดเดาแทนเรา
4. ถ้าข้อมูลยังไม่ครบ ให้ถามต่อจนได้โครงที่พร้อมใช้

## Practice 2: เปลี่ยนคำตอบเป็น Copilot Page

#### Steps

1. ใต้คำตอบของ Copilot เลือกปุ่มรูปดินสอ **Edit in Pages**
2. ตรวจว่า Page เปิดอยู่ด้านข้าง Copilot Chat
3. เลือกชื่อ Page แล้วเปลี่ยนเป็น `Weekly Reporting Improvement Brief`
4. แก้ `[ต้องระบุ]` อย่างน้อย 1 จุดด้วยข้อมูลตัวอย่างที่ผู้สอนกำหนด
5. วาง prompt ด้านล่างใน Copilot Chat เพื่อปรับ Page

```text
ปรับ Page นี้ให้เหมาะสำหรับการประชุมเริ่มโครงการ
เพิ่มหัวข้อ "คำถามที่ต้องตัดสินใจ" จำนวน 3 ข้อท้าย Page
คงข้อความ [ต้องระบุ] ในจุดที่ยังไม่มีข้อมูลยืนยัน
```

6. ตรวจว่า Copilot เพิ่มเนื้อหาใน Page โดยไม่ลบส่วนสำคัญเดิม
7. ทดลองแก้ข้อความบน Page โดยตรงอีก 1 จุด

## Practice 3: แชร์และตรวจการทำงานร่วมกัน

#### Steps

1. เลือก **Share** บน Page
2. เลือกผู้รับตามที่ผู้สอนกำหนด หรือคัดลอก link ด้วยสิทธิ์ที่องค์กรอนุญาต
3. ส่ง Page ผ่าน Microsoft Teams หรือ Outlook
4. ให้ผู้รับเปิด Page และเพิ่มข้อความ `ตรวจสอบแล้วโดย [ชื่อ]` ในส่วนท้าย
5. กลับมาที่ Page และตรวจว่าการแก้ไขของผู้รับปรากฏขึ้น

> หาก policy ไม่อนุญาตให้แชร์ ให้หยุดก่อนส่ง link และสาธิตเฉพาะการสร้างกับแก้ไข Page

## Checkpoint

- Page เปิดจากคำตอบด้วย **Edit in Pages** และมีชื่อที่สื่อความหมาย
- Page มีเป้าหมาย ขอบเขต ผู้เกี่ยวข้อง ตัวชี้วัด แผนงาน และความเสี่ยงครบ
- ข้อมูลที่ยังไม่ยืนยันแสดงเป็น `[ต้องระบุ]`
- ผู้รับที่ได้รับอนุญาตเปิด Page ได้และการแก้ไขปรากฏบน Page เดียวกัน

## Expected Output

- Project Brief บน Copilot Pages 1 Page
- การแก้ไขจาก Copilot 1 จุด การแก้โดยตรง 1 จุด และการแก้จากผู้ร่วมงาน 1 จุด

## Optional Extension

- เปิด Microsoft 365 Copilot Library แล้วค้นหา Page ที่สร้างไว้ เพื่อทดลองกลับมาใช้งานต่อภายหลัง
