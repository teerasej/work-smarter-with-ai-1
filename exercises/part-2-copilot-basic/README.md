# Part 2 — Copilot Basic

## Exercise

ในระดับ part 2 นี้ เราจะขยับมาฝึกใช้ Copilot Chat, Copilot Create, Prompt Gallery และ Copilot Pages ก่อนนำไปใช้กับสถานการณ์ธุรกิจสามแบบใน Copilot-in-Action

## Scenario

เลือกใช้ไฟล์ใน [`../../files/part-2/`](../../files/part-2/) ที่พลเตรียมไว้ให้เฉพาะ หลีกเลี่ยงการใช้ข้อมูลจริงขององค์กรนะครับ

ดาวน์โหลดไฟล์ตัวอย่างทั้งหมดของ Part 2 ได้ที่ [part-2-sample-files.zip](https://github.com/teerasej/work-smarter-with-ai-1/raw/main/files/part-2/part-2-sample-files.zip) แล้วแตกไฟล์ zip ก่อนเริ่มทำแบบฝึกหัด
