# Part 2 — Copilot Basic

## Exercise

ฝึกใช้ Copilot Chat, Copilot Create, Prompt Gallery และ Copilot Pages ก่อนนำไปใช้กับสถานการณ์ธุรกิจสามแบบใน Copilot-in-Action

## Scenario

เลือกใช้ไฟล์ใน [`../../files/part-2/`](../../files/part-2/) เฉพาะเมื่อกิจกรรมระบุไว้ หลีกเลี่ยงการใช้ข้อมูลจริงขององค์กร

## Practice map

| Practice | Primary target | Checkpoint / expected output | Capability-gated fallback |
| --- | --- | --- | --- |
| [Copilot Chat](exercise-folders/copilot-chat.md) | เริ่ม chat, ปรับ prompt และใช้ไฟล์เป็น context | ได้คำตอบที่ตรวจทานและนำไปต่อยอดได้ | ใช้ browser-based Copilot Chat หรือวางข้อความจากไฟล์แทนการอัปโหลด |
| [Copilot Create](exercise-folders/copilot-create-mode.md) | สร้าง visual และตรวจความถูกต้อง | ได้ visual พร้อมคำอธิบายสิ่งที่ต้องตรวจ | ร่าง visual brief ด้วย Copilot Chat แล้วสร้างด้วยเครื่องมือที่องค์กรอนุญาต |
| [Prompt Gallery](exercise-folders/copilot-prompt-gallery.md) | เลือก ปรับ และบันทึก prompt | ได้ prompt ที่ปรับให้ตรงงานสื่อสาร | เก็บ prompt ในเอกสารส่วนตัวหาก Save/Share ไม่พร้อม |
| [Copilot Pages](exercise-folders/copilot-pages.md) | เปลี่ยนคำตอบเป็น Page ที่แก้ไขร่วมกัน | ได้ project brief ที่แชร์เพื่อ review ได้ | คัดลอกคำตอบไป Word หรือ OneNote เพื่อทำงานร่วมกัน |
| [Copilot-in-Action](exercise-folders/copilot-in-action/copilot-in-action.md) | ใช้ Copilot กับโจทย์งานจริงจำลอง | ได้ outline, tracker หรือ summary ตาม use case | ใช้ Copilot Chat พร้อมไฟล์ตัวอย่างและบันทึกผลลัพธ์ในแอป Office ที่มี |

กิจกรรมแต่ละรายการมี Scenario, Steps และ prompt จากแหล่งต้นทางที่ตรึงเวอร์ชันแล้ว อ่านข้อกำหนดสิทธิ์ในแต่ละกิจกรรมก่อนเริ่ม
